# Dark Material palette for MCA level names

Dark Material palette for MCA level names

## Usage

``` r
material_colors_dark()
```

## Value

A character vector of color codes, with color names.

## Examples

``` r
material_colors_dark()
#> Deep purple 300      Orange 700 Light green 600        Teal 400         Red 700 
#>       "#65499c"       "#bb4d00"       "#4b830d"       "#00766c"       "#9a0007" 
#>        Lime 800       Brown 400      Purple 300        Pink 300       Green 800 
#>       "#6c6f00"       "#5f4339"       "#883997"       "#ba2d65"       "#00600f" 
#>        Blue 400   Blue Grey 500 
#>       "#0077c2"       "#34515e" 
```
