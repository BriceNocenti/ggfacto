# Correspondence Analysis of a Crosstab

Makes the correspondence analysis of a crosstab with
`FactoMineR::`[`CA`](https://rdrr.io/pkg/FactoMineR/man/CA.html): first
make the table with
[`tabxplor::tab()`](https://bricenocenti.github.io/tabxplor/reference/tab.html),
then analyse it. The analysis reads the (weighted) counts of the table,
whatever it displays, without its Total rows and columns. To leave out
some rows or columns, filter the table before, with
[`dplyr::filter()`](https://dplyr.tidyverse.org/reference/filter.html)
and
[`dplyr::select()`](https://dplyr.tidyverse.org/reference/select.html).

**Supplementary variables** are given in the table itself: in a
\`tab()\` of several row variables, or several column variables, the
first row variable and the first column variable make the active table,
and the other variables are supplementary, placed on the axes without
taking part in them. \`tab(data, c(relig, marital), c(partyid, race))\`
analyses \`relig\` by \`partyid\`, and places the levels of \`marital\`
by their profile over \`partyid\`, and the levels of \`race\` by their
profile over \`relig\`.

## Usage

``` r
correspondence_analysis(table, ncp = Inf, ...)
```

## Arguments

- table:

  A crosstab made with
  [`tabxplor::tab()`](https://bricenocenti.github.io/tabxplor/reference/tab.html),
  with one or several row variables and one or several column variables.
  A matrix or a `table` of counts works too, with its supplementary rows
  and columns given as in
  [`FactoMineR::CA()`](https://rdrr.io/pkg/FactoMineR/man/CA.html)
  (\`row.sup\`, \`col.sup\`).

- ncp:

  The number of axes to keep. All of them by default.

- ...:

  Additional arguments to pass to
  [`CA`](https://rdrr.io/pkg/FactoMineR/man/CA.html).

## Value

A \`CA\` object from FactoMineR, which remembers the names of the two
active variables, so that
[`interpret`](https://bricenocenti.github.io/ggfacto/reference/interpret.md)
can print them, and, in \`source\`, the variable and the name of every
row and column of the table.

  dplyr::filter(!relig %in% c("No answer", "Don't know", "Not applicable"),
                !partyid %in% c("No answer", "Don't know"))

res.ca <- correspondence_analysis(crosstab)
interpret(res.ca)                            # the eigenvalues, then the axes
